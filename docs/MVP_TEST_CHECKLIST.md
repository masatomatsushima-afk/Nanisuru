# Nanisuru MVP テストチェックリスト

実機（Expo Go / 開発ビルド）とブラウザで、友人テスト前に確認してください。

## 前提

- `.env` に OpenAI / Supabase / Google Maps のキーが設定されていること
- テスト用アカウント（メール）を1つ用意しておくこと
- 問題があれば **マイページ → フィードバックを送る** から報告

---

## A. 初回起動

- [ ] アプリが起動する（赤画面・クラッシュなし）
- [ ] オンボーディング or ホームに到達できる
- [ ] ホームが表示される（真っ白画面にならない）
- [ ] 下部タブ（ホーム / 保存 / 発見 / 旅行秘書 / マイページ）が切り替わる

## B. 旅行プラン生成

- [ ] ホームから旅行プラン作成フォームを開ける
- [ ] 行き先を入力できる
- [ ] 出発日・帰宅日 / 泊数を選べる
- [ ] 予算・通貨を入力できる
- [ ] 予算に含める項目（チップ）を選べる
- [ ] 同行者を選べる
- [ ] 旅行の目的を選べる（任意）
- [ ] 「プランを生成」をタップできる
- [ ] 「プランを作成中」オーバーレイが表示される
- [ ] 生成後、プラン詳細（行程・予算・天気など）が表示される
- [ ] 開発者向けエラー文が画面に出ない

## C. プラン編集・保存

- [ ] 行程の部分編集が開ける
- [ ] 天気に合わせた再調整（表示される場合）が動く
- [ ] 「このプランを保存」が動く、またはログインプロンプトが出る
- [ ] 未ログイン時は「ログインが必要です」と分かりやすい

## D. マイトリップ

- [ ] マイページ → マイトリップ、またはホームから開ける
- [ ] 保存したプランが一覧に出る（ログイン + Supabase 設定時）
- [ ] 旅行秘書フォルダが一覧に出る
- [ ] 保存プランを開いて詳細が見られる
- [ ] フォルダから旅行秘書を開ける

## E. 旅行秘書

- [ ] メッセージを送信できる
- [ ] クイックチップがタップできる
- [ ] AI 返答が表示される（OpenAI 設定時）
- [ ] 変更提案の「プランに反映」がクラッシュしない

## F. 当日モード

- [ ] プラン詳細から当日モードを開ける
- [ ] 「今の予定」「次の予定」が表示される
- [ ] クイックアクション（Maps / 遅れてる 等）が動く
- [ ] 遅延調整 UI が開ける
- [ ] 雨プラン（表示される場合）が開ける

## G. 思い出

- [ ] 思い出アルバム / 一覧が開ける
- [ ] メモを追加できる
- [ ] 写真を選ぶ操作でクラッシュしない（未設定時は準備中メッセージ）
- [ ] AI サマリー（表示される場合）が動く

## H. 発見 / マイページ / 穴場

- [ ] 発見タブが開き、フィード or 空状態が表示される
- [ ] マイページが開く
- [ ] ローカルの穴場一覧が開く
- [ ] 穴場投稿フォームが開く
- [ ] 公開 / 非公開の切り替えでクラッシュしない

## I. 好み設定

- [ ] 好みオンボーディング / 設定画面が開く
- [ ] カテゴリ・ペースなどを選んで保存できる
- [ ] 保存後、プラン生成に反映される（ログ確認 or 生成結果で確認）

---

## 推奨メインフロー（友人向け）

1. ホーム → 旅行プラン作成  
2. 入力 → プラン生成  
3. 詳細確認 → 保存（ログイン）  
4. マイトリップで確認  
5. 旅行秘書で1メッセージ送信  

## 開発者向け

- 開発ビルドのみ: マイページ下部 **「テストデータをリセット」** でローカルキャッシュをクリア（Supabase 本番データは触りません）
- バージョン表示: **Nanisuru MVP v0.1**
